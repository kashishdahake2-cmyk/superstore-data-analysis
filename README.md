Superstore Sales Analysis 📊

Project Overview

This project analyzes Superstore sales data using Python to understand sales performance, profitability, and business trends.

Dataset

- Dataset: Sample Superstore
- Total Records: 9,994
- Total Columns: 21

Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

Analysis Performed

1. Total Sales and Profit Analysis
2. Region-wise Sales Analysis
3. Category-wise Sales Analysis
4. Top 10 Products by Sales
5. Monthly Sales Analysis
6. Region-wise Profit Analysis
7. Category-wise Profit Analysis
8. Top 10 Loss-Making Products
9. Data Visualization

Key Findings

- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12.47%
- Highest Sales Region: West
- Highest Sales Category: Technology
- Most Profitable Region: West
- Most Profitable Category: Technology

Conclusion

This project helps identify sales trends, profitable regions, and loss-making products to support better business decisions.
